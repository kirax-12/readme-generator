# Generator README

**Demo live:** [readme-generator di GitHub Pages](https://kirax-12.github.io/readme-generator/)

Web app statis buat membuat README.md GitHub yang rapi dalam semenit: isi form (nama proyek, deskripsi, fitur, teknologi, cara menjalankan, lisensi, link demo), lalu salin markdown-nya atau unduh langsung sebagai file README.md. Dilengkapi pratinjau hasil render yang diperbarui langsung setiap ketikan.

Dibuat oleh **Remike Dev**.

## Fitur

- **Form sederhana** — nama proyek, deskripsi, link demo live, penulis, fitur (satu per baris), teknologi, langkah menjalankan, dan pilihan lisensi (MIT, Apache-2.0, GPL-3.0).
- **Dua tampilan hasil** — tab Markdown (kode mentah siap salin) dan tab Pratinjau (sudah dirender seperti tampilan di GitHub).
- **Salin & unduh** — tombol salin ke clipboard dan unduh file `README.md` jadi.
- **Live** — hasil berubah otomatis setiap input berubah, tanpa tombol submit.
- Struktur output mengikuti pola README yang baik: judul, deskripsi, demo, fitur, cara menjalankan, teknologi, lisensi.

## Cara Pakai

1. Isi form sesuai proyekmu.
2. Cek tab Pratinjau kalau mau lihat hasilnya seperti di GitHub.
3. Klik **Salin Markdown** atau **Unduh README.md**, lalu pasang di repo kamu.

## Teknologi

HTML · CSS · JavaScript murni (termasuk renderer markdown mini untuk pratinjau), tanpa framework dan tanpa build step.
